# 仕訳スキル

## 作業手順

ユーザーが「仕訳して」と言ったら以下を実行する：

1. `python3 accounting.py import` を実行
2. `python3 accounting.py status` で未分類取引を確認
3. DBの過去仕訳（journalsテーブル）を参照して分類方針を確認
4. 未分類取引を分類し、journalsテーブルに書き込む
5. 曖昧な取引はユーザーに確認してから書き込む
6. 全件完了後に `python3 accounting.py export` を実行
7. 判断に迷った仕訳を一覧でユーザーに報告する

## journalsテーブルへの書き込み

```sql
INSERT INTO journals (
  transaction_id, seq, tx_date,
  dr_account, dr_sub, dr_amount, dr_tax, dr_tax_type, dr_inout, dr_invoice,
  cr_account, cr_sub, cr_amount, cr_tax, cr_tax_type, cr_inout, cr_invoice,
  description, memo, is_uncertain, uncertain_reason, classified_at
) VALUES (?, 1, ?, ?, '', ?, ?, ?, '', ?, ?, '', ?, ?, ?, '', ?, ?, '', 0, '', ?);
```

- `seq`: 同一取引から複数行生成する場合の連番（手数料など）
- `is_uncertain`: 要確認のとき 1
- `classified_at`: `datetime('now', 'localtime')`

## 伝票No命名規則

フォーマット: `[口座コード(2桁)][YYMMDD][連番(2桁ゼロパッド)]`

| 口座 | コード | 例 |
|---|---|---|
| 銀行 | 01 | 0125120101 |
| クレジットカード | 02 | 0225120101 |
| 証券 | 06 | 0625120101 |
| 手動調整 | 07 | 0725123101 |
| 立替 | 08 | 0825120101 |

- 同一取引から複数行（seq≥2）は同じ伝票番号を使う
- **13桁以上禁止**（全力会計のint32上限を超えてエラー）

## 税額の計算

- 課対仕入10%（内税）: `税額 = round(金額 / 11)`
- 対象外: 税額 = 0

## Noインボイスの値

| 値 | 意味 |
|---|---|
| 0 | 対象外 or 分類不要 |
| 1 | インボイスあり |
| 2 | インボイスなし（80%控除） |
| 3 | インボイスなし（50%控除） |

- 課対仕入10% → 1
- 対象外 → 0

## 税区分

| 用途 | 税区分 | 内外区分 |
|---|---|---|
| 仕入・費用（内税） | 課対仕入10% | 内税 |
| 売上（内税） | 課税売上10% | 内税 |
| 売上返還 | 課税売返10% | 内税 |
| 受取利息 | 非課税売上 | **別記**（空欄不可） |
| 銀行振替・税金等 | 対象外 | 空欄 |

## 摘要の記号制限

**使用可能な記号のみ**: `( ) / . , 半角スペース`

変換ルール（この順序で適用）:
1. NFKC正規化（半角カタカナ→全角）
2. 全角スペース → 半角スペース
3. 全角カッコ `（）` → 半角 `( )`
4. 半角ハイフン `-` → 半角スペース
5. その他使用不可記号 → 半角スペース
6. 連続スペース圧縮

`normalize_desc()` 関数（accounting.py）を使うこと。

## メモの記号制限

使用可能: `( ) / . , [ ] : ? & = # _ + % @ 半角スペース`

`≒` は使用不可 → `=` で代替（例: `1USD=153.5円`）

## 普通預金の補助科目

補助科目名は口座ごとに任意に設定する（例: 「メインバンク」「証券口座」など）。

## 未払金の補助科目

| 補助科目 | 用途 |
|---|---|
| （任意） | 個人カード立替（例: 「代表者」） |

## 按分ルール（クレジットカード）

自宅兼事務所など事業と個人が混在する費目は按分して計上する。按分率は各自の事業用途割合に応じて設定する。

| 費目 | 按分率（例） | 勘定科目 |
|---|---|---|
| 家賃 | XX% | 地代家賃 |
| 保証料 | XX% | 地代家賃 |
| 電気代 | XX% | 水道光熱費 |

- 残（100-XX）%は個人用途のため計上しない
- 電気・ガスが同一請求の場合は事業用分のみ按分・計上し、個人用分は除外する

## 典型的な仕訳パターン

### クレジットカード
```
家賃・保証料:  DR 地代家賃 (金額×按分率)    /  CR 未払金/[補助科目]  税区分:対象外
ショッピング:  DR 消耗品費等                /  CR 未払金/[補助科目]  税区分:課対仕入10%
返金:          DR 未払金/[補助科目]         /  CR 元の費用科目
個人利用除外: [個人利用業者名] → スキップ
```

### スキップ処理

「個人利用除外」に該当する取引はjournalを作成せず、以下のSQLでskipフラグを立てる：

```sql
UPDATE transactions SET skip=1, skip_reason='個人利用' WHERE id=?;
```

- skipしないとstatusの「未分類取引」にカウントされ続けるため必須
- 役員報酬相殺分は import時に自動skip済み

### 銀行
```
売上入金:           DR 普通預金/[補助科目]  /  CR 未収入金
受取利息:           DR 普通預金/[補助科目]  /  CR 受取利息  (非課税売上/別記)
法人カード支払:     DR 未払金/[カード名]    /  CR 普通預金/[補助科目]
源泉税(税務署):     DR 預り金/所得税        /  CR 普通預金/[補助科目]
立替精算振込:       DR 未払金/[補助科目]    /  CR 普通預金/[補助科目]
外注費支払:         DR 外注費              /  CR 普通預金/[補助科目]
売上返金:           DR 売上高(課税売返10%) /  CR 普通預金/[補助科目]
```

### 証券
```
株式購入: DR 投資有価証券      /  CR 普通預金/[補助科目]
株式売却: DR 普通預金/[補助科目]  /  CR 投資有価証券
```

### 売上返還（顧客返金）
```
DR 売上高  課税売返10%  内税  Noインボイス:0
CR 普通預金/銀行口座  対象外
```
